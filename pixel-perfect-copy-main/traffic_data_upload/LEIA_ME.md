# Instruções para Upload de Dados de Tráfego

Por favor, adicione seu arquivo CSV ou Excel nesta pasta (`traffic_data_upload`).

As colunas esperadas são:
- date_start
- date_stop
- account_id
- campaign_id
- campaign_name
- adset_id
- adset_name
- ad_id
- ad_name
- objective
- valor_investido
- impressoes
- alcance
- frequencia
- cliques_no_link
- ctr_link
- link_cpc
- cpm_all
- ctr_all
- cpc_all
- views_pagina_destino
- custo_por_view_pagina_destino
- id_geral

Assim que o arquivo for colocado aqui, poderemos processá-lo para atualizar o dashboard.
